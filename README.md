🎮 Guess & Learn!
Guess & Learn! est une application web éducative interactive conçue pour les enfants. Elle propose une collection de mini-jeux ludiques permettant aux plus jeunes d'apprendre en s'amusant : les couleurs, les animaux, les chiffres, les fruits, les formes, les légumes, les vêtements, le corps humain, les métiers et les lettres.

🎯 Aperçu
L'application se présente sous forme d'une page d'accueil colorée et animée, où chaque catégorie d'apprentissage est représentée par une carte illustrée. Chaque carte propose deux modes :

Play 🎲 : un jeu interactif de type "devine et apprends" où l'enfant doit reconnaître le bon élément.

Learn 📚 : un mode découverte qui affiche tous les éléments de la catégorie avec leur nom.

🌟 Autres fonctionnalités
Interface adaptée aux enfants : typographie ludique (Comic Neue, Fredoka One), couleurs vives et animations.

Design responsive : adapté aux ordinateurs, tablettes et smartphones.

Animations de récompense : étoiles, fleurs, confettis et cercles animés lors des bonnes réponses.

Bouton de retour en haut pour une navigation fluide.

Grille de cartes interactive avec effets de survol.

Mode jeu et mode apprentissage pour chaque catégorie.
